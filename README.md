# zmusicstats

整合网易云音乐、QQ 音乐与 Apple Music 的个人听歌统计，生成适配手机和电脑的网页报告及分享图片。

## 已确定的方向

- 项目名：`zmusicstats`，全小写、无空格。
- 用户首次连接音乐账号后，由程序获取数据，不要求手动导出或上传文件。
- 首版关注可获取的周期统计和 Top 歌曲、歌手，不要求全部历史或逐次播放日志。
- 核心分析、文案组合、图表和分享图片不依赖逐用户调用 AI。
- 手机与电脑均为正式支持场景。

详细需求、数据边界和验证顺序见 [第一版需求](docs/product-brief.md)。

## 本地运行

需要 Node.js 22.19+ 或 24+。

```sh
npm install
npm run setup:netease
# 初次使用：复制 .env.example 为 .env，设置 NETEASE_API_BASE_URL=http://127.0.0.1:3101
npm run dev
```

打开 http://localhost:5173。手机与电脑连接同一个局域网时，可使用启动时显示的 Network 地址。开发服务会启动前端、账号连接服务及已安装的本地网易云服务。关闭终端或停止开发进程后网站停止运行。

## 已实现

- 黑胶风格响应式仪表盘，三平台示例、月份切换、曲目搜索与平台筛选。
- 完整中英文界面；中文 Noto Serif SC／Noto Sans SC，英文 Instrument Serif／Manrope，本地字体资源。
- 真实统计规则、缺失数据处理、曲风样本分析；无需大模型调用。
- 本地生成 PNG 封面、长图和四张系列卡；中英及深浅主题；设备支持时调用系统分享。
- 网易云真实扫码接口已验证能够创建二维码并等待扫码；用户账号数据尚未实测。
- Apple Music 官方 MusicKit 授权与数据适配已编写，需开发者配置后验证。
- QQ 连接适配已编写，尚未启用实际网关。

## 当前数据边界

首次打开的是**明确标注的示例报告**。Apple Music 示例时长不是已经从 Apple 接口获得的真实时长。

网易云时长字段待真实账号核对，未核实前保持缺失。QQ 的生产接入方式与使用许可待确认。Apple Music 当前适配读取最近播放及歌曲标签，不声称能获取任意月份的听歌次数、完整排行或实际时长；未知周期曲目单独注明，不冒充月榜。

同一台手机完成网易云／QQ 首次连接仍待实机验证；当前网易云二维码适合电脑显示、手机扫描。报告浏览、筛选和海报生成已按手机尺寸适配。仅本地开发，尚未公开部署。
