# zmusicstats

整合网易云音乐、QQ 音乐与 Apple Music 的个人听歌统计，生成适配手机和电脑的网页报告及分享图片。

[线上界面预览](https://zmusicstats.vercel.app) 使用明确标记的示例数据；真实账号连接目前在本机版使用。

## 已确定的方向

- 项目名：`zmusicstats`，全小写、无空格。
- 用户首次连接音乐账号后，由程序获取数据，不要求手动导出或上传文件。
- 首版关注可获取的周期统计和 Top 歌曲、歌手，不要求全部历史或逐次播放日志。
- 核心分析、文案组合、图表和分享图片不依赖逐用户调用 AI。
- 手机与电脑均为正式支持场景。

详细需求、数据边界和验证顺序见 [第一版需求](docs/product-brief.md)。

## 本地运行

需要 Node.js 22.19+ 或 24+。

```sh
npm install
npm run setup:netease
npm run setup:qq
# 初次使用：复制 .env.example 为 .env，按其中说明配置本机音乐服务。
npm run dev
```

打开 http://localhost:5173。手机与电脑连接同一个局域网时，可使用启动时显示的 Network 地址。开发服务会启动前端、账号连接服务及已安装的本地网易云服务。关闭终端或停止开发进程后网站停止运行。

## 已实现

- 先连接账号、再选择月份；可读取平台实际开放的历史月份，逐月展示读取状态。
- 单页黑胶风格报告：音乐画像、来源占比、歌曲排行、曲风、跨平台共同偏爱和分享海报。
- 电脑逐屏浏览，排行区独立滚动；手机连续浏览。排行支持 Top 5/10/20/50/100、自定义与分页。
- 完整中英文界面；中文 Noto Serif SC／Noto Sans SC，英文 Instrument Serif／Manrope，本地字体资源。
- 真实统计规则、缺失数据处理、曲风样本分析；无需大模型调用。
- 本地生成 PNG 封面、长图和系列卡，可选择内容及曲目数量，包含专辑封面；支持中英及深浅主题。
- 时间可切换小时、天、月、年，配合自然、日常和天文等不同尺度的比喻；不会调用逐用户 AI。
- 网易云与 QQ 真实扫码、账号显示和月度数据已在本机验证；手机直接唤起 App 的最终授权仍需实机验证。
- Apple Music 官方 MusicKit 授权与数据适配已实现；开发者配置与订阅账号授权是不同步骤，订阅账号端到端验证尚未完成。

## 当前数据边界

首次打开连接页面；用户可主动进入明确标注的示例报告。示例数据不代表真实平台授权结果。

网易云只统计实际取得的已结束月份，历史范围取决于上游对该账号开放的数据。QQ 未取得官方总时长时，以有明确周期的排行样本“次数 × 歌长”估算，显示约等号及样本说明；汇总含估算时也显示约等号，不将样本当成全部收听历史。

曲风分布只纳入播放次数大于 10 的已取得歌曲；多曲风按标签均分权重。缺少可靠曲风的歌曲不猜测标签，并展示识别覆盖情况。跨平台合并忽略大小写和封面差异；不同歌曲版本的合并属于近似匹配。

Apple Music 当前适配读取最近播放及歌曲标签，不声称能获取任意月份的听歌次数、完整排行或实际时长；未知周期曲目单独注明，不冒充月榜。

网易云与 QQ 为非官方网页接口适配，上游接口变化、地区网络及账号风控可能导致失败。手机 App 跳转提供明确错误与扫码回退；浏览器尺寸模拟不能代替 iPhone 实机授权测试。

## 本地数据与部署

账号凭据保存在本机 `.auth-state/` 的加密文件内，不回传给网页，也不提交到仓库。`.env`、私钥、缓存和真实报告均排除在版本控制之外。

当前完整功能需要前端、连接 API 和音乐平台网关共同运行。GitHub Pages 只能承载静态网页，不能替代连接 API；云部署需先处理持久化会话、后台历史读取和网关部署，不能直接将本机开发服务器当成可横向扩容的云服务。
