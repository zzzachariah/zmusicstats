# Visual direction — records, revisited

用户已选择：黑胶风格；可探索仪表盘＋独立分享海报；中英文切换。

主意象是唱片本身：凹槽映出光线、唱片中心纸标提供信息、唱片套排列承载曲目。避免把所有信息放进相同卡片，也避免霓虹灯和装饰性玻璃。

Palette: carbon #141515, shell #1c1d1c, paper #eee9df, ink-muted #a7a69e, vermilion #d57757, brass #c5b58a。

Type: Avenir Next / system sans for interface, Songti SC / Georgia for restrained display, system monospace for dates and durations. Display wording stays personal but does not infer psychological traits.

Layout: quiet top navigation; generous split hero (period + title + record); time and platforms integrated below; ranked track rows beside style breakdown; a wide share callout. Mobile stacks naturally and keeps all controls reachable.

Signature: the data record — concentric grooves, a rotating surface, a fixed center label and platform sectors that reflect the supplied report. Its motion is decorative and can be paused, with reduced-motion respected.

Interactions: 180–320ms opacity/transform transitions; chart fills on entry; restrained stagger; period/tab switches preserve position; modal focus trapping and escape close. Avoid continuous large parallax or cursor-follow effects.

Demo is always explicitly marked. Connection states never imply a successful platform login without an actual response. All user-visible controls, empty states, and report labels support Chinese and English.
