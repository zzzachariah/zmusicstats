# 第一版需求

确认日期：2026-11-24。

## 用户流程

1. 打开网页，创建或恢复本站账户。
2. 连接网易云音乐、QQ 音乐或 Apple Music，并由本人完成首次登录确认。
3. 将其他平台绑定到同一个本站账户。
4. 后台获取可用数据，显示覆盖的日期和平台。
5. 自动生成报告，支持下载分享图片。

音乐平台登录与本站会话分别管理。连接第二个平台时，不根据昵称自动合并账户。

## 首版报告

- 平台听歌时长及占比：优先选已连接平台都可获取的完整月份。
- 各平台 Top 5／10 歌曲和歌手。
- 多个平台共同上榜的歌曲和歌手。
- 曲风偏好，以及在数据支持时生成的曲风分布。
- 一张总览分享海报及分项分享卡片。

跨平台总榜只有在歌曲版本、日期范围和统计口径可比较时才生成。

## 不依赖在线 AI 的生成方式

- 普通程序负责汇总、排序、比例与变化计算。
- 优先使用平台曲风信息，必要时维护有来源的歌曲标签库。
- 文案提前创作和审核，根据真实指标选择模板并填入数据。
- 背景、插画和版式可以提前制作；用户海报通过程序排版导出。
- 同一周期的结果可以缓存，避免每次打开都重新取数。
- 数据及所需素材缓存后，分析和图片生成可设计为浏览器本地运行；登录及刷新数据仍需联网。

## 手机与电脑要求

- 手机优先的响应式布局，同时适配宽屏电脑。
- 图表、排行和海报预览在窄屏下无需横向滚动。
- 支持触控、鼠标及键盘操作。
- 在 iPhone Safari、Android Chrome 和电脑主流浏览器验证核心流程。
- 手机端验证图片保存／分享，电脑端验证图片下载。
- 电脑连接：网页显示二维码，手机 App 扫码确认。
- 单手机连接：必须另行验证同机完成登录的路径；不能把“手机扫码”视作“一台手机即可完成”。
- 网易云有短信验证码登录的文档，可作为单手机连接的候选路径，需实测。
- QQ 当前检查的第三方接口提供二维码图片和状态轮询，尚未验证同机跳转授权或相册扫码。

## 数据准确性

- 时长占比使用同一日期范围、同一单位的真实累计听歌时长。
- 不用歌曲长度乘播放次数代替实际收听时长。
- 缺失数据不记为零；没有可比较数据时，不生成跨平台时长占比。
- QQ 官方周报的 listenTime 是日均时长，不能直接当作周总量。
- QQ 官方月报中 topGenre.genre2Count 覆盖近六个月，不能直接称为本月曲风。
- 网易云曲风偏好接口没有周期参数，不能默认其代表选定月份。
- 如果只分析 Top N 歌曲，应明确标为基于这些歌曲的偏好。
- 曲风缺失保留为未识别，不根据歌名猜测。
- 不用听歌偏好推断真实心理诊断或敏感个人特征；趣味标签仅描述音乐习惯。

## 接入核查状态

目前为公开文档及源码研究，尚未进行真实账号验证。

- 网易云第三方项目提供二维码登录、周／月排行、时长报告和曲风偏好接口。
- QQ 第三方项目提供扫码登录、周期报告和歌曲曲风接口；具体返回字段和覆盖范围待实测。
- QQ 官方 Skills 提供结构化报告，但使用个人 API Key，不等同于已开放的第三方网站扫码授权。
- 第三方接入的运行稳定性与面向公众使用的许可需分别确认。已找到的 QQ 第三方项目声明不可商用，不能直接视作正式产品的商用接入授权。

## 实施验证顺序

1. 验证一个账号的网易云登录及可用字段。
2. 验证 QQ 接入路径、可用字段和使用范围。
3. 验证只有一台手机时的首次连接流程。
4. 用双方都覆盖的一个完整月份核对时长、排行和曲风口径。
5. 实现无需 AI 的计算、模板文案、响应式报告与海报导出。
6. 完成手机及电脑实际浏览器验证，再决定公开上线范围。

## 2026-11-24 开发确认

- 用户选定黑胶风格、可探索仪表盘与独立海报，中英文切换。
- 用户要求细致设计中英字体；海报支持长图及多张系列卡，展示更多信息。
- 首先在本机运行，验证后再上线。
- Apple Music 属于首版范围，不能遗漏；用户已有 Apple Developer 账号，凭证稍后在本机配置。
- 用户指出唱片中心标签和底部说明/控制错位，已改为SVG固定坐标标签与独立底部行。
- 当前实现与待实测边界见 README.md，较早的研究笔记不代表已完成真实账号验证。
