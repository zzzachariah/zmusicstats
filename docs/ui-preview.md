# 线上界面预览

此模式仅用于静态部署和界面体验，使用项目内置的虚构听歌数据。它不能连接真实网易云、QQ 音乐或 Apple Music 账号，不提供二维码授权，也不加载 MusicKit。欢迎页、管理连接和报告顶部均标注“界面预览 · 使用示例数据”。示例月份、排行榜、曲风分析和海报导出仍可使用。

构建命令：

```sh
ZMUSICSTATS_UI_PREVIEW=true npm run build
```

只发布生成的 `dist/` 静态目录。这个构建不依赖后台服务，不要附带 `.env`、`.auth-state/`、Apple 私钥或本机报告缓存。真实账号恢复、授权和历史读取的客户端代码会从预览产物中移除。

开关只在构建时读取，网址参数和浏览器存储不能切换它。没有设置此环境变量时，`npm run dev` 和 `npm run build` 保留本机完整连接流程。需要恢复真实连接的版本，应在未设置开关的环境中重新构建；不要将本机共享授权存储直接作为公开多用户服务发布。

线上真实连接还需要独立的用户身份、凭据隔离和云端读取任务架构，此预览不表示这些功能已经上线。
