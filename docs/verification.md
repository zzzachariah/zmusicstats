# 本地与界面预览验证

更新：2026-11-25。

## 已验证

- 本机网易云与 QQ 音乐扫码确认后，连接状态、账号名称和实际月度数据成功恢复。历史只纳入上游实际返回的月份；未提供的内容不编造。
- 网易云真实时长与 QQ 有周期排行样本估算分开标注，汇总包含估算时显示约等号；每首歌保留来源口径。
- 桌面六节独立布局、单行收窄导航、排行内部滚动及边界停顿。1280×720 的曲风页、分享页和加载页在单屏内展示；1024×650 的首屏另做紧凑排版。
- 320px 与 390px 手机宽度检查；320px 首屏时长已缩放至内容边界内。浏览器尺寸测试不等同于 iPhone 实机授权。
- 排行支持默认 Top5、预设、自定义和最多 100 首一页；导出可单独选择 Top5/10/20 或自定义数量。
- 真实报告的 Top37 导出生成连续编号的两张图；Top5 长图实际下载为 1080×3321，歌曲及共同偏爱封面成功加载。部分上游封面不可用时保留明确的替代数量提示。
- 海报顶部与首页一致：音乐画像和人物抱唱片，单独固定 Z；中文标题经过实际 PNG 视觉复核，修复了句号独占行。
- 时间单位切换按钮预留最宽值与固定说明高度，平台按钮位置不会随单位跳动。
- 比喻库 120 个独立条目；按时长筛选适合的条目，保存各实体洗牌进度，并避开其他实体最近 16 个条目。刷新续接、整轮不重复、存储损坏/拒绝、时长变化与 Strict Mode 重放均有自动测试。
- 本机构建和静态预览构建通过。预览产物没有账号恢复、授权、历史、资料读取及 MusicKit 代码；真实平台按钮禁用，始终明确标记示例数据。
- 发布文件扫描排除了 `.env`、私钥、加密会话、真实报告及工作缓存。测试二维码和凭据均为合成数据。

## 仍待验证

- iPhone 在同一台手机跳转网易云/QQ 音乐 App 并返回网页完成授权；目前只验证了链接构造、轮询及失败回退。
- Apple Music 实际订阅账号的授权与数据读取。开发者配置已完成，用户因没有订阅跳过了实际账号验证。
- 云端真实账号连接：会话持久化、可恢复历史任务及 QQ 音乐 App 中继需要后续改造和云端验证。公开网页仅为明确标识的静态界面预览，不能宣称三平台云端连接已完成。
- 真实 iOS 系统分享及不同浏览器的下载体验。
